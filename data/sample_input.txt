==============================================================
CONTOH INPUT - Sistem 3x3
==============================================================

Sistem persamaan:
  2x1 + 1x2 - 1x3 =  8
 -3x1 - 1x2 + 2x3 = -11
 -2x1 + 1x2 + 2x3 = -3

Input ke program:
  n = 3

  Matriks A:
    2   1  -1
   -3  -1   2
   -2   1   2

  Vektor b:
    8
   -11
   -3

Solusi yang diharapkan:
  x1 = 2
  x2 = 3
  x3 = -1

==============================================================
CONTOH INPUT - Sistem 2x2 (sederhana untuk demo)
==============================================================

Sistem persamaan:
  2x1 + 3x2 = 12
  5x1 - 2x2 =  1

Input ke program:
  n = 2

  Matriks A:
    2   3
    5  -2

  Vektor b:
   12
    1

Solusi yang diharapkan:
  x1 = 1.578947...
  x2 = 2.947368...

Verifikasi manual:
  2(1.578947) + 3(2.947368) ≈ 3.157894 + 8.842104 ≈ 12 ✓
  5(1.578947) - 2(2.947368) ≈ 7.894735 - 5.894736 ≈  1 ✓
